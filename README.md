# Manabi-Zaurus｜かんじザウルス教育RPG

小学1・2年生が、RPGの冒険を楽しみながら漢字を学ぶ教育ゲームアプリです。モジラと恐竜を漢字の手がかりで助けながら、まぼろしのティラノサウルスを探します。現在は「はじまりの森」を最後まで遊べる体験版です。

- 第1章で出会う漢字：草、肉、大、小
- 目的：困っているトリケラトプスを助け、まぼろしのティラノの足あとを見つける
- 対応：iPhone、iPad、Mac、Windows PC
- オフライン起動とホーム画面追加に対応するPWA
- セーブは端末内だけ。外部への送信やアクセス解析はありません

## 必要なもの

- Node.js 20以上（推奨：22）
- npm 10以上
- Safari、Chrome、Edgeの新しいバージョン

Node.jsが入っているかは、ターミナルで確認できます。

```bash
node --version
npm --version
```

## 初めて起動する

ターミナルを開き、このフォルダへ移動します。

```bash
cd /Users/matsukawatakamasa/Documents/codex-project/dino-kanji-adventure
```

必要な部品をインストールします。最初の1回だけ必要です。

```bash
npm install
```

ゲームを起動します。

```bash
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開きます。ポート番号が5173以外になる場合は、ターミナルに表示されたURLを使ってください。

## 停止する

ゲームを起動したターミナルで、次のキーを押します。

```text
Control + C
```

## 再起動する

同じフォルダで、もう一度実行します。

```bash
npm run dev
```

## 公開用にビルドする

```bash
npm run build
```

成功すると、公開用ファイルが `dist` フォルダに作られます。公開前に手元で確認するには次を実行します。

```bash
npm run preview
```

## テストする

```bash
npm run test
```

学習進捗、復習優先度、セーブの読み書き、初期データ、第1章の物語と漢字選択を確認します。

## 操作方法

### PC・Mac

- 移動：矢印キー、またはW・A・S・D
- 調べる：Enter、またはSpace
- 会話・問題：画面の大きなボタンをクリック

### iPhone・iPad

- 移動：画面左下の方向ボタン
- 調べる：画面右下の「しらべる」、または光る対象をタップ
- 縦画面でも使えますが、横画面のほうがマップを広く見られます

## セーブデータ

セーブデータはブラウザの `localStorage` に保存されます。保存キーは次のとおりです。

```text
yukkuri-lab-dino-kanji-save-v2
```

次のタイミングで自動保存します。

- 場面を進めたとき
- 漢字問題に答えたとき
- 恐竜・アイテムを見つけたとき
- 設定を変えたとき
- タイトルへ戻るとき

壊れたデータを見つけた場合は、安全な初期データで起動し、元の文字列を `yukkuri-lab-dino-kanji-save-v2-broken` に退避します。

### セーブデータを消す

タイトルの「おうちの ひと」を開き、`3 + 4` の答えを入力します。画面下の「最初から やり直す」を押し、確認に同意してください。

ブラウザの開発者ツールから保存キーを削除することもできますが、通常は保護者画面の操作をおすすめします。

## iPhone・iPadで開く

開発中に同じWi-Fi内で確認する方法です。

1. MacまたはPCで `npm run dev:ipad` を実行します。
2. ターミナルに表示される `Network` のURL（例：`http://192.168.1.10:4174/`）を確認します。
3. iPhoneまたはiPadを同じWi-Fiへ接続します。
4. SafariでそのURLの末尾に `?v=watercolor-hero` を付けて開きます。

```text
http://192.168.1.10:4174/?v=watercolor-hero
```

ファイアウォールの確認が表示された場合は、家庭内ネットワークからの接続を許可してください。学校・会社など制限のあるWi-Fiでは接続できないことがあります。
MacとiPadのセーブデータは別々です。iPadで始めた進み具合は、そのiPadのSafariに保存されます。

## ホーム画面へ追加する

### iPhone・iPad（Safari）

1. 公開済みのゲームをSafariで開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. 「追加」を押します。

初回読み込み後は主要ファイルが保存され、オフラインでも起動できます。開発用URLではなく、HTTPSで公開したURLでの利用を推奨します。

### PC（Chrome・Edge）

アドレスバーに表示されるインストールアイコン、またはブラウザメニューの「アプリをインストール」を選びます。

## 公開方法の候補

`npm run build` で作られる `dist` フォルダを静的サイトとして公開します。

- Netlify：`dist` をドラッグ＆ドロップして試しやすい
- Cloudflare Pages：Gitリポジトリと連携しやすい
- Vercel：Viteプロジェクトを自動判定しやすい
- GitHub Pages：無料で公開できるが、サブパス用の設定調整が必要

子どもの利用を想定するため、必ずHTTPSを使い、広告・解析・外部送信を追加しない運用をおすすめします。

## よくあるエラー

### `npm: command not found`

Node.jsが入っていません。Node.js 20以上をインストールし、ターミナルを開き直してください。

### `EADDRINUSE` または「ポートが使用中」

別の開発サーバーが動いています。動いているターミナルで `Control + C` を押すか、表示された別ポートのURLを開いてください。

### 画面が白い

ターミナルに赤いエラーがないか確認し、依存部品を入れ直します。

```bash
npm install
npm run dev
```

### 音や読み上げが出ない

- 最初に画面を1回タップしてください。ブラウザは操作前の音声再生を止めることがあります。
- ゲームの「設定」で音量と読み上げを確認してください。
- 端末が消音モードでも、ゲームは文字だけで進められます。
- `speechSynthesis` 非対応環境では読み上げなしで続行します。

### 更新したのに古い画面が出る

PWAのキャッシュ更新に少し時間がかかる場合があります。タブを閉じて開き直してください。開発中はブラウザのサイトデータを消す方法もありますが、セーブも消えるため注意してください。

## 240字へ増やす方法

1. `src/data/kanji.ts` に `KanjiItem` 形式のデータを追加します。
2. `src/data/story.ts` または新しい章データから、その `kanjiId` を使う問題を追加します。
3. 学年・難易度・場面タグを設定します。
4. 復習エンジンは全データから優先度を計算するため、文字ごとの専用処理は不要です。
5. まとまりが大きくなったら、学年・単元ごとにデータファイルを分割し、`kanji.ts` で結合します。

追加例：

```ts
{
  id: 'g1-sora',
  character: '空',
  grade: 1,
  readings: ['そら', 'クウ'],
  hiragana: 'そら',
  meaning: '見上げた ひろい ところ',
  exampleWords: ['空', '青空'],
  exampleSentence: '空を 見上げます。',
  difficulty: 1,
  relatedSceneTags: ['sky']
}
```

追加後は必ず確認します。

```bash
npm run test
npm run build
```

## 主なフォルダ

```text
src/
  app/                 アプリ全体と画面切り替え
  components/          タイトル、問題、図鑑、保護者画面など
  data/                漢字、恐竜、物語データ
  features/learning/   学習進捗と復習ロジック
  features/save/       初期データとlocalStorage
  game/                Phaserマップ、移動、イベント連携
  styles/              レスポンシブデザイン
  types/               共通の型
  utils/               効果音と読み上げ
public/icons/          PWAアイコン
```

## プライバシー

バックエンド、外部データベース、広告、Google Analyticsなどの解析ツールは使用していません。ユーザーの進捗は、そのブラウザの端末内だけに保存されます。
